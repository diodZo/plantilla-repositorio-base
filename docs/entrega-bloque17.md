# Entrega Bloque 17

Archivos incluidos:
- `docs/revision_manual_bloque17.json`: revisión propuesta de 10 respuestas reales con rúbrica y notas.

Copia los archivos dentro de la carpeta `docs/` del repositorio y revisa/ajusta tus juicios antes de entregarlos. Conserva el `docs/resultados_metricas.json` original como fuente de las veinte respuestas.

Comandos:
```powershell
git add docs/resultados_metricas.json docs/revision_manual_bloque17.json docs/limites_metrica.md
git commit -m "Documenta revision cualitativa y limites del Bloque 17"
git push origin main
```
